## `01` — Sobre mim

Sou Alexsandro Costa Nunes, profissional da área de **Engenharia de Dados e Analytics**.

Tenho interesse em construir soluções que transformem dados em informação útil, com foco em organização, processamento, automação e análise.

Minha stack reúne ferramentas para trabalhar com dados, estruturar pipelines e apoiar processos analíticos. Também desenvolvo projetos de software que conectam APIs, regras de negócio e persistência de dados.

Gosto de entender o problema antes de escolher a ferramenta — porque uma solução eficiente começa com uma boa arquitetura.

<div align="center">

  **Dados bem estruturados. Processos automatizados. Soluções que funcionam.**

</div>
